## Installation Instructions

1. Clone the repo
   ```bash
   <navigate to desired directory>
   git clone https://github.com/saikoukunt/dLDS.git
   cd dLDS
   ```

2. Install necessary packages (first launch julia and press ] to enter the package manager)
    ```bash
    (v1.12) pkg> activate .
    (DLDS) pkg> instantiate
    ```
